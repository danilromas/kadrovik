# Кадровик — job-платформа с HRM/ATS

Frontend платформы для поиска работы и подбора сотрудников (в духе hh.ru / LinkedIn Jobs): соискатели ищут вакансии и откликаются, работодатели ведут кандидатов по воронке, администраторы модерируют контент.


## Демо

**https://danilromas.github.io/kadrovik/**

Вход с любым паролем под демо-аккаунтами:

| Роль | Email |
|---|---|
| Соискатель | candidate@demo.ru |
| Работодатель | employer@demo.ru |
| Рекрутер | recruiter@demo.ru |
| Администратор | admin@demo.ru |

Данные — моковые, хранятся в браузере. ИИ-ассистент в демо не работает (ему нужен серверный прокси, запускается через `npm run dev`).

## Возможности

- **Публичная часть:** главная, каталог вакансий и компаний с фильтрами, каталог и просмотр резюме
- **Кабинет соискателя:** профиль, несколько резюме, отклики и их статусы, избранное, чат, уведомления
- **Кабинет работодателя / HR:** компания, вакансии, отклики, ATS-воронка кандидатов (Kanban с drag & drop), аналитика
- **Админ-панель:** обзор платформы и модерация
- **Авторизация и роли:** соискатель, работодатель, рекрутер, админ; защищённые маршруты и отдельные layout'ы под каждую роль
- Mock API с задержками и ошибками — фронтенд работает автономно, без бэкенда

## Стек

React · TypeScript · Vite · Tailwind CSS · shadcn/ui (Radix UI) · React Router · Zustand · TanStack Query · react-hook-form + zod · dnd-kit · Recharts · Framer Motion

Архитектура — feature-based: `entities/`, `features/`, `widgets/`, `pages/`, `shared/`.

## Запуск

```bash
pnpm install
pnpm dev      # dev-сервер
pnpm build    # прод-сборка
```
