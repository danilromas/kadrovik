## Сценарии (кратко)

1. **Логин / регистрация** — формы с Zod: неверный email, короткий пароль, несовпадение паролей, галочка «условия» на регистрации.
2. **Регистрация закрыта** — в админке «Настройки» выключить «Регистрация открыта», открыть `/register` — кнопка неактивна, предупреждение.
3. **Режим обслуживания** — включить в настройках «Режим обслуживания» — жёлтый баннер в `MainLayout`.
4. **Кандидат** — `/dashboard`, отклики с загрузкой через React Query, вакансии скрытые админом не попадают в рекомендации.
5. **Вакансии** — `/vacancies`: индикатор загрузки, фильтры; скрытая админом вакансия исчезает из списка.
6. **Деталь вакансии** — `/vacancies/:id`: загрузка, отклик с выбором резюме и письмом (валидация Zod).
7. **Работодатель** — `/employer/dashboard`, отклики с привязкой к вакансиям из Query.
8. **Админ** — пользователи, компании, **вакансии** (скрыть / удалить из выдачи / восстановить), **резюме** (скрыть / отклонить / сброс), настройки (persist в `localStorage`).
9. **Модератор** — вход `moderator@demo.ru`: в сайдбаре только дашборд, очередь модерации, компании, вакансии, резюме (без пользователей, аналитики, настроек).
10. **Очередь модерации** — `/admin/moderation`: демо-жалобы со ссылками.
11. **Каталог резюме** — `/resumes`: фильтр по **языку**, скрытые админом карточки не показываются.
12. **Чат** — `/dashboard/messages`: сообщения сгруппированы по дню (Сегодня / Вчера / дата), при открытии чата входящие помечаются прочитанными (двойная галочка на своих).
